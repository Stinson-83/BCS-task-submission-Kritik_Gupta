# Dance of the Planets

## Contents
- `Dance_of_the_Planets.ipynb`: Contains the entire implementation
    - User input
    - Data generation using solve_ivp
    - Model definition and training
    - Evaluation with MAE and plots

## Final Performance
- MAE: ~5,100,000 meters
- ~1.3% error compared to Earth-Moon distance
- Model trained for 3000 epochs using L1 loss
